# 真实 Forward 描述性评估合同 V1

版本：`forward-evaluation-contract-v1.0`。

评估层只读取已经原子封存的 Forward Observation 与到期 Outcome。T+1、T+5、T+10、T+20 均表示封存序列中的真实后续交易日，不使用自然日、程序运行次数或合成日期替代。

结果按五类结构、核心/一般研究带和观察周期分别统计。Outcome 必须通过 `(security_id, signal_observation_id)` 绑定到产生信号时的队列，禁止用当前分类回写历史信号。相同结果主键内容冲突时阻断。

每组至少需要 30 条完整结果且覆盖至少 5 个不同信号交易日，才公布中位收益、25%/75%分位、样本内正收益比例、中位最大上行和中位最大回撤。样本不足时这些指标保持空值，只公布已到期数、有效数、不可用数和日期数。

“样本内正收益比例”只是已观察样本的描述，不是未来上涨概率。评估层不修改候选规则、阈值、排序、经济模型身份或生产发布，也不生成自动交易指令。
