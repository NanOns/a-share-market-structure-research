# M11-05 联动 UI 合同 V1

合同 ID：`M11_LINKAGE_UI_V1`  
适用计划：`workbench-upgrade-plan-v2.1`  
阶段：M11-05（预览）

## 页面结构

联动页面包含三个独立子页面：属性库、关联联动、交叉筛选。顶部条件区显示当前选择和查询口径；选择栏可折叠，折叠不清除条件。主结果区使用横向滚动容器，宽表不得冲出页面。

## 数据与交互

- 属性库调用 API23，按类型、语义桶和名称/ID搜索；标签显示为标签，不能自动提升为强势关联。
- 关联联动调用 API25，支持板块查股票和股票查板块；成员名次来自快照，筛选只影响展示，不重新排名。
- 交叉筛选调用 API24，明确显示纳入板块、交集/并集和排除板块；空集合不伪装成无条件查询。
- 结果提示显示 `snapshot_id`、截止日和 `history_basis`；无数据或分析未构建时显示可读空状态，不渲染原始 HTML。
- 分页只改变展示页，不改变集合运算、排名或关联资格。
