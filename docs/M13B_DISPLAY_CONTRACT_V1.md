# M13B-03 收盘梯队与晋级展示合约 V1

## 1. 范围

- `contract_id`: `LIMIT_DISPLAY_V1_0`
- 阶段：M13B-03
- 页面：M7 v2「市场周期」内的「收盘梯队 / 晋级历史」切片
- 数据源：API34 `/api/limit-ladder`、API35 `/api/limit-ladder/promotion-history`

本阶段只负责可解释展示，不在浏览器端推导涨停、连板、晋级分母或晋级率。

## 2. 展示字段

### 收盘梯队

筛选固定为 `level=ALL/1/2/3/4PLUS`、标准 `state` 和 `promotion`；表格显示交易日、证券、状态、连续层级、连续天数、晋级状态和规则版本。列表沿用 API34 的分页/排序结果，未知状态单独显示。

### 晋级历史

筛选固定为 `days` 与 `previous_level=ALL/1/2/3/4PLUS`；表格显示前一日层级、成功数、合格分母、描述性比率、未知/停牌/无涨跌幅限制排除数、前一日涨停总数和未确认数。比率为空时显示“暂无”，不能显示为 0%。

## 3. 能力状态与空态

- API 返回 `status=NOT_BUILT` 时，显示“尚未构建”及依赖说明，不渲染空表冒充零样本。
- API 返回 `AVAILABLE` 但 `items/points=[]` 时，显示“当前快照暂无可展示行”，与 `NOT_BUILT` 分开。
- 合约、快照、历史基础和能力字段进入页面说明；未知、停牌和无涨跌幅限制不合并成失败。
- 外部文字全部使用 DOM `textContent`；不使用 `innerHTML` 或客户端 HTML 拼接。

## 4. 验收

- 页面切片从当前发布版本读取固定分析快照。
- API34/API35 的 NOT_BUILT、AVAILABLE 数据和 rate=NULL 均能正确渲染。
- 默认包含科创板和北交所统计口径的说明；本切片不自行隐藏或改写后端范围。
