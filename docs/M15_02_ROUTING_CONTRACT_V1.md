# M15-02 路由与版本合同 v1

## 目的

M15-02 收口统一工作台 v2 的页面边界和可恢复导航，不改变分析口径、发布身份或旧版历史查看入口。

## 页面合同

v2 只有六个一级页面：

| 路由页 | 页面 | 二级内容 |
|---|---|---|
| `overview` | 研究总览 | API30/API31 首页摘要 |
| `sectors` | 板块 | `sectors` 板块周期、`mainlines` 主线周期 |
| `stocks` | 个股技术 | 新高/RPS、技术状态 |
| `linkage` | 联动 | 属性库、关联联动、交叉筛选 |
| `market` | 市场周期 | 市场历史、收盘梯队、请求时热榜 |
| `data-info` | 数据能力 | 发布上下文、合同、覆盖和降级说明 |

候选池通过总览“优先研究”进入；队列通过市场周期进入。它们不是独立一级导航，避免与同一数据域重复建页。

## URL 合同

`/v2` 页面使用以下受控查询参数：

- `page`：六个一级页面之一；缺省为 `overview`。
- `subpage`：仅在 `page=sectors` 时使用，允许 `sectors` 或 `mainlines`。
- `publication_id`：当前成功发布版本身份；切换版本时更新并清空隐含交易日。
- `trade_date`、`basis`：为历史视图预留，未提供时不猜测、不跨发布补齐。
- `security_id`、`tab`、`days`：个股透视抽屉状态，绑定当前 `publication_id`。

未知页面和二级值回退到安全默认页；不执行客户端路径、不接受任意静态文件名。

## 交互与恢复

一级导航和二级导航使用 `pushState`；后退/前进读取 URL 并恢复页面。刷新先解析 URL，再在 API01/API02 完成当前发布上下文后加载目标页。发布切换保留页面和二级页，个股抽屉关闭不丢失页面上下文。

个股透视沿用统一 modal 的抽屉语义：打开时写入 URL，关闭、遮罩、关闭键和 `Escape` 均清理透视参数；焦点返回原触发控件，异步响应使用请求序号和 AbortController 防止旧响应覆盖新状态。

## 兼容与滚动

`/v2`、`/v2/` 和 `/v2/index.html` 继续由同一静态资源白名单提供；旧 `/view?publication_id=...` 保留作为历史回看入口。v2 页面不嵌套 iframe，不新增第二个页面级纵向滚动容器；表格和抽屉只在自身需要时横向/内部滚动。

## 验收边界

本阶段验证路由合同、静态页面挂载、旧入口兼容、modal 关闭和异步失效保护。1440x900/1920x1080 的真实浏览器录制和性能预算属于 M15-03/M15-04，不在本阶段宣称完成。
