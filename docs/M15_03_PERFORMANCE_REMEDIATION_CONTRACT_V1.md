# M15-03 性能修复合同 V1

## 阶段目标

针对 `M15-03-PERFORMANCE-BUDGET` 的服务端首请求瓶颈进行可复核修复，不改变 API 返回字段、排序、发布身份或数据口径。

## 修复范围

- 报价读取支持按页面 `security_id` 做 Parquet 谓词下推；完整报价读取仍保留给需要全量范围的调用。
- API31 的强势关联计算只读取计算所需的成员排名、有效样本和 RET5/RET20 字段，不再解析每个成员的完整 JSON payload。
- v2 首页先等待发布身份并启动 API30/API31；股票范围摘要后台完成，不再阻塞首页主流程。

## 约束

- 只读数据库和本地封存输入；不修改 TDX、历史发布、快照或观察结果。
- 不改变 M6 外审状态，不切换正式入口。
- 浏览器端 30 次热操作仍须单独实测，服务端接口重复测量不得冒充浏览器证据。

## 验收与下一阶段

服务端冷/热测和定向回归通过后，M15-03 仍保留 `release_ready=false`，直到固定视口浏览器证据完成并与原合同同协议复测。下一阶段为 M15-04 数据/恢复重审，重新核查 T22 及继承的性能审计项。
