# M3 自动输入合同 V1

版本：`m3-automatic-input-v1.1`。

仅接受 `https://data.tdx.com.cn/vipdoc/hsjday.zip`。下载先写受管目录中的 `.part`，校验声明长度、ZIP 魔数、中央目录和 SHA-256 后原子发布；失败半包删除。SHA-256 仅代表收到的字节，不冒充官方签名。

解压拒绝路径穿越、绝对路径、盘符路径、符号链接、大小写冲突，并限制条目数、总展开字节和单条压缩比。所有输出位于项目受管目录，不写通达信源目录。

元数据以 manifest A、稳定窗口、复制、manifest B 和副本哈希四步封存。稳定性与结构完整性分别记录；没有可靠完成信号时新鲜度为 `UNKNOWN`。动态目录识别新增证券、新板块、成员加入/退出；成员引用不存在的证券时阻断。

`source_bundle-v1.0` 绑定目标交易日、官方包身份、解压证据、元数据快照、交易日历和解析器版本。M3 只封存只读输入，不发布业务结果；正式事务发布属于 M4。

任何消费者在使用 bundle 前必须重新计算 bundle 身份、官方包 SHA-256、元数据逐文件哈希，并重新扫描解压日线。JSON 中的 `read_only` 字段本身不作为完整性证据。验收入口动态选择最新日期，不允许写死日期、包大小或复制旧 PASS。
