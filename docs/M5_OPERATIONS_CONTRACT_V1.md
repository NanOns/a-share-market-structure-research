# M5 运维功能合同 V1

## 目标与范围

本阶段只管理工作台自身的运行配置、受管存储、数据库迁移、备份恢复和受控重启。`D:/new_tdx` 及配置中的任何通达信目录始终是只读输入，绝不纳入清理、迁移或备份写入目标。

## 子任务与顺序

1. 配置中心：草稿、校验报告、带版本条件的应用和生效修订记录。
2. 存储治理：受管根登记、租约、三日保留清理预览及隔离删除恢复。
3. 一致性备份与恢复演练：暂停写入、关闭数据库、备份、试开和业务抽检。
4. 跨盘数据库迁移：临时副本校验、切换、失败回退。
5. 受控重启：排空、释放单所有者锁、健康检查及旧配置回退。

每一子任务必须先有合同测试，再做真实目录或服务操作；不得因开发或测试删除现有工作台数据。

## 安全不变量

- 拒绝盘符根目录、工作区根目录、通达信根、符号链接/Junction 穿越及相互包含的受管路径。
- 清理只允许处理 `storage_objects` 中已登记、无有效租约且不被数据库引用的对象；数据库、WAL 和 owner lock 永不清理。
- 配置应用使用 `expected_revision` 比较并写入新的不可变 revision；运行中的任务固定其启动 revision。
- 备份或迁移只能从已关闭的一致性数据库副本执行；目标副本必须试开并核验发布头、队列、成员及 Forward。
- 重启失败必须恢复旧配置；禁止双写者同时持有数据库 owner lock。

## M5 验收门槛

路径逃逸、租约、重启失败回退演练均须通过，并形成带实际目录、版本、数据库抽检结果的回执，才可标记 M5 PASS。磁盘满故障演练由验收方明确豁免，不作为本轮 M5 的前置条件。
