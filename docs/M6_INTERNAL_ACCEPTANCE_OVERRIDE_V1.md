# M6 用户内部验收修订 v1

版本：`M6_INTERNAL_USER_ACCEPTANCE_V1_0`  
适用范围：当前工作区的 M6 验收与 M15 正式入口门控。  
覆盖关系：本修订仅覆盖 `docs/M6_INDEPENDENT_ACCEPTANCE_CONTRACT_V1.md` 中关于“独立验收方”“外部验收”和 `EXTERNAL_AUDIT_PASS` 的角色及结论要求；数据、身份、性能、恢复、只读和不改历史发布等技术约束继续有效。

## 验收主体

本项目不存在第三方验收方。验收主体为项目用户；Codex 依据用户授权执行内部复核、整理证据并代用户形成验收回执。`EXTERNAL_AUDIT_PASS` 不再作为本项目的必需状态，也不得继续作为等待条件。

## M6 内部验收标准

- M0–M5 回执链全部通过。
- 当前本地发布头中指定的两个真实交易日完成数据、身份、接口和页面证据复核。
- 五类队列、证据、分页、板块成员数量、成员名次和联动检查通过。
- 查询性能使用实测值；故障恢复、重启回退和发布幂等证据通过。
- 不修改 TDX 输入、历史发布、观察结果、结果表或模型规则，不使用未来数据和网络数据。

## 结论与边界

满足上述条件时，M6 记为 `INTERNAL_USER_ACCEPTED`，M6 自身的 `production_entry_switch_allowed` 可置为 `true`。这只表示 M6 验收门通过，不代表 M15-03/M15-04 或 M15-05 的其他门自动通过；正式入口仍须逐项满足当前 M15 合同。
