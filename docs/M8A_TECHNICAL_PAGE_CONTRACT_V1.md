# M8A-04 个股技术页合同 v1

`/v2` 的“个股技术”页是 API10、API11、API12 的只读消费层。页面以当前选择的
`publication_id` 为边界，不自行计算因子、不访问 TDX 源目录，也不改变正式发布头。

- “创新高-RPS”使用 API11，窗口固定从 20/30/60/100 日中选择；RPS 门槛使用
  接口返回的 `rps20`，连续新高使用 `streak`，并保留质量码与 NULL。
- “技术状态”使用 API10，支持 `ma_state` 与 `amount_class` 筛选；均线、收益和量额
  字段只展示接口快照中的值，缺失值显示为 `—`，不参与客户端补值。
- 表格固定分页请求，上一页/下一页由接口 `total` 和 `page_size` 控制；当前快照、basis
  和质量说明显示在表格上方。
- 每行的“历史”按钮调用 API12，并把 `price_basis=ADJUSTED`、快照身份和最新点放入
  证据弹窗；接口返回的 `RPS_NOT_BUILT` 等能力状态直接显示给用户。
- 页面通过 DOM `textContent` 写入结果，不把服务端字段拼接进 `innerHTML`。

本步骤仅完成前端接入与契约测试；M8A 分析快照仍由后端显式构建和绑定，不能因打开
页面而自动构建或激活。
