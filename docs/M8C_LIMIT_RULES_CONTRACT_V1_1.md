# M8C-02 涨跌停规则合同 v1.1

`LIMIT_RULES_V1_1` 是 M8C 审计后的规则合同。规则数值仍来自本地固定配置，但“规则存在”不等于“规则已核验”。每条规则必须带 `rule_verified`、`source_sha256`、`audit_status`、审核时间和有效区间；同一 `rule_id` 内容改变必须生成新身份并拒绝静默覆盖。

计算器只在以下证据同时明确时输出 `LIMIT_UP`、`LIMIT_DOWN` 或 `NOT_LIMIT`：

- 交易所、板块、风险状态和交易日有效区间已逐日绑定；
- 参考价状态为 `KNOWN`，且来源、交易日连续性和除权除息状态已证明；
- 上市阶段为已知普通交易阶段；
- 规则 `rule_verified=true`；
- 当日收盘价为有效、正数、符合最小价位精度，并落在计算边界内。

任一必需证据缺失、边界冲突、除权参考价未核验或规则未核验，输出 `UNKNOWN`，并保留原因码。已知无涨跌幅限制、停牌与未知状态分离，不把它们转换为 `NOT_LIMIT`。

规则算法为 Decimal 精确计算：`previous_reference × (1 ± limit_ratio)`，按规则声明的 tick 和舍入模式取整；仅当交易所条款和本地证据共同允许时，才应用最小价位边界政策。该合同不允许运行时联网、未来数据或默认比例。
