# M8C-01 参考价/股本能力合同 v1

`REFERENCE_CAPABILITY_V1_0` 只登记本地参考数据能力，不宣称已经具备精确涨跌停或
换手率计算能力。每行按 `security_id + trade_date` 唯一，并保留参考前收、流通股本、
单位、股本口径、来源、观察时间和规则登记状态。

- 参考前收与流通股本分别给出 `EXACT`、`UNKNOWN`、`UNAVAILABLE`；数值缺失写 NULL，
  数值非正、来源缺失或单位/口径未核验时不标精确。
- 只有股数单位为 `SHARES`/`股`、股本口径为已知流通股本、数值和来源均有效时，换手率
  参考能力才为 `EXACT`。成交量不会被转换成股本，也不会冒充换手率。
- `rule_id` 可登记待执行规则版本；缺失时为 `UNREGISTERED`。M8C-01 不计算涨跌停价，
  不硬编码 10% 规则，后续规则实现必须单独带生效日期和边界样本。
- 适配器只处理截止日及以前的输入，拒绝未来行和重复键；写入 007 已有
  `market_reference_daily` 时保持 slice 不可变。不会修改 TDX 源目录。
