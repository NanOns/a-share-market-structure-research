# P12-14 每日可选换手率编排验收

## 阶段合同

本阶段把P12-14换手率增强和影子观察接到 `run_p12_daily_pipeline.py` 的本地V3.3研究包成功后置步骤。在线增强始终是可选项：来源、解析、超时、报告或封存失败均不得回滚活动研究包，不得让页面“一键生成本地数据”失败。

## 实现

- 本地V3.3完整研究包生成并通过身份检查后，调用一次 `run_p12_14_daily_turnover.py`。
- 若同一交易日、同一研究包已经存在影子观察，直接复用摘要，不再次访问东财。
- 首次处理新研究包时，按P12-14合同读取全部沪深候选，每批最多50只并顺序执行，任一批失败即停止；8秒超时、零重试；随后只封存通过本地目标日指纹绑定的标准化行。
- 来源不可用时返回 `OPTIONAL_DEGRADED`，主流水线仍返回 `READY`。子进程超时、异常退出或报告损坏也走相同非阻断分支。
- 主流水线响应增加 `optional_enhancements.turnover`，页面任务状态可以区分本地研究成功与在线增强降级。
- 换手率观察不改变活动指针、研究包摘要、候选顺序、类别、分数或排名。
