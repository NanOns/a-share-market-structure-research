# P12-14 V3.3候选全集换手率增强验收

## 阶段合同

本修正把换手率的输入范围定义为活动V3.3研究包中全部受支持的沪深候选。请求按最多50只顺序分批，任一批失败后停止，不重试，不保存原始响应，也不阻断本地主流程。

换手率不改变候选准入、核心V3.3评分或既有类别排名。对 `QUALIFIED_UNRANKED` 候选，系统依据已通过目标交易日指纹绑定的换手率，计算研究包内活跃度百分位，并在相同主类别和相同选择模式内生成二级增强序号。来源不可用或指纹不匹配时，增强序号为空，继续使用V3.3原顺序。

## 实际范围

- 活动研究包交易日：2026-09-15。
- 活动研究包候选：56只。
- 可增强沪深候选：54只，其中沪市25只、深市29只；北交所2只由合同明确跳过。
- 当前候选状态：53只 `QUALIFIED_UNRANKED`，3只 `SCORED`。
- 计划请求：50只和4只，共2批。是否能绑定取决于东财源当次可用性和本地日线指纹匹配结果。

## 系统接入

- API返回全部标准化换手率证据和 `enhanced_items`，包含活跃度百分位、活跃度分层及类别内增强序号。
- 页面提供“应用换手率增强”，显示换手率和换手增强序号，并明确核心评分及类别排名不变。
- 每日可选流程封存通过指纹绑定的换手率、活跃度百分位、分层和增强序号，供后续复核与效果审计。
- 失败分支保持空值，不填0，不改变本地候选，不影响一键生成结果。
