# P12-14 生成期换手率增强接入验收

## 问题

旧实现把在线查询放在页面按钮后，且每日流程会复用绑定数为0的失败观察。2026-09-16实测页面请求54只沪深候选时，东财主源第一批即发生 `RemoteDisconnected`，所以页面显示0只可用；重新生成同一研究包也不会重试。

## 修复

- 换手率在线获取只在V3.3生成流水线完成研究包后执行。
- 页面接口只读取与活动研究包摘要绑定的物化观察，不再发起外部请求；页面加载候选后自动读取增强结果。
- 绑定数为0的失败观察不再阻止下一次生成重试；只有已有成功绑定行时才复用。
- 东财批量接口失败时启用版本化的腾讯行情备用合同，继续使用同一候选批次、8秒超时、零重试、响应上限和本地目标日指纹校验。
- 备用源字段明确映射价格、源时间、成交额、手数和换手率；手数转换为股，换手率百分数转换为小数。
