# P12-14 可选换手率来源候选记录

本文件最初只登记候选来源。`P12-11`、`P12-12`、`P12-13`及170日物化完成后，已于2026-09-16进入正式 `P12-14`；最终合同、用途设计和验收结论见 `P12_14_TURNOVER_VALIDATION_AND_DESIGN_20260916.md`。

东方财富个股行情页面及其网页动态行情接口可提供当日换手率、量比、成交额、总市值和流通市值。验证样本 `SZ.002491` 在2026-09-15的实时接口与历史日线接口均返回换手率22.70%；全市场列表接口当时报告5559只证券并支持分页。字段属于网页内部动态接口，未视为稳定的正式开发者API。

候选使用方式限定为**本地初筛后的数据增强**：通达信只读本地数据完成全市场主筛，随后仅对候选池发起有上限的小批量请求。禁止为了170日历史物化逐证券扫描全市场；数千次集中请求存在限流、熔断、字段变化及来源不可用风险。东财失败、超时、返回日期错配或字段异常时，换手率必须标记为 `UNAVAILABLE`，不得阻断本地一键生成，不得用成交量或成交额冒充换手率，不得改变本地publication、snapshot或bundle身份。

后续 `P12-14` 正式阶段需要补齐版本化来源合同、字段语义与缩放核对、证券代码映射、交易日绑定、请求预算、超时和退避、缓存时限、时间戳、原始响应摘要、能力门、故障降级和小样本对账。是否保存增强结果须在该阶段单独决定；本记录不授权全市场抓取，也不执行任何网络采集。
