# P12-14 换手率页面接入验收

## 阶段合同

本阶段在 `P12_14_EASTMONEY_CANDIDATE_TURNOVER_V1` 已完成来源验证之后，只接入V3.3候选页面、只读API和详情证据。换手率仍是本地初筛后的可选增强，不进入候选准入、类别判定、评分、排名、研究包身份或发布门；本阶段不启动影子效果统计。

## 实现

- 新增 `GET /api/v3/research/today-turnover?bundle_digest=...`。接口先验证活动研究包摘要，处理研究包中的全部沪深候选，按最多50只顺序分批。
- 2026-09-16修正：接口返回换手增强结果，对 `QUALIFIED_UNRANKED` 生成同类别、同选择模式内的二级序号；核心V3.3评分与类别排名不变。
- 页面新增“加载换手率”按钮。打开页面不会自动访问东财；用户点击后才执行一个批量请求。
- API复用P12-14的8秒、200 KB、零重试合同，并以本地目标日的收盘价、成交额和成交量绑定来源结果。
- 同一研究包的成功或失败结果缓存15分钟，避免连续点击造成重复外部请求；并发读取由服务锁串行化。
- 候选表增加“换手率”列；详情增加换手率数值、能力状态、来源口径和证据原因。缺失或失败显示不可用，不填0，不移除候选。
- 来源错误只返回错误类型，不把底层异常详情或原始响应带到页面；API不持久化原始响应。
