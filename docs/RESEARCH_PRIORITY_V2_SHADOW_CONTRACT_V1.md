# Research Priority V2 Shadow Contract v1.0

Ruleset `research-priority-v2-shadow-v1.0`; Shadow only; production eligible is false.

`V2_PRIORITY_IS_QUEUE_BASED = TRUE`, `V2_GLOBAL_WEIGHTED_SCORE = FALSE`, and `STRUCTURE_COUNT_STACKING = FALSE`. Five independent queues map only frozen V2 hit classes to `CORE` or `SUPPORTED`. Leader has no global privilege. Pullback non-contracted volume receives no new penalty. Non-hit classes remain diagnostic context.

The unified board contains each V1 candidate exactly once. Any one CORE tier yields `CORE_RESEARCH`; without CORE, any SUPPORTED yields `SUPPORTED_RESEARCH`; otherwise the V1 candidate is `DIAGNOSTIC_ONLY`. Multiple hits never upgrade these bands, weak/data-insufficient classes never cancel another structure, and counts are descriptive only. No V2 A+/A/B/C rating exists.

Queue display is tier then security ID only and is explicitly `DISPLAY_ORDER_ONLY = TRUE`, not an economic rank. V1 primary pattern and rating are comparison context. Overlap, V1/V2 cross-tabs, and Leader coverage are descriptive multi-membership audits; coverage totals may exceed 100%.

Identity binds all five source receipts/rulesets plus this contract and implementation. No external/network data, index OHLC, future evidence, backtest, weighted score, quota, probability, recommendation, automated trading, V1 mutation, or production publication is permitted.
