# 强势回撤 V2.1 影子合同 V1

规则版本：`strong-pullback-v2.1-shadow-v1.0-recent-peak-anchor`。状态：历史兼容影子实现，`production_eligible = FALSE`。其“最近一次峰值、峰值只进入上涨段”的修复语义已经并入默认 V2 v1.1；本实现仅用于读取或复核旧 V2.1 产物，不再代表比默认 V2 更新的经济规则。

V2.1 只修正回撤锚点和成交分段口径，不调整 V2 的深度阈值、分段阈值、成交收缩阈值或分类含义。计算窗口是截止日及以前最近 20 根有效实际交易柱，不读取未来数据。

峰值锚点统一为窗口内最高复权收盘价最后一次出现的位置。峰值日期、峰值价格、距峰值交易柱数、当前回撤深度和成交额分段必须共同使用这个位置。上涨段从窗口起点到峰值柱，包含峰值柱；回撤段从峰值后的第一根柱开始，不包含峰值柱。峰值成交额不会重复进入两个分段。

上涨段至少需要 2 根有效柱，回撤段至少需要 1 根。没有峰值后交易柱时，成交比例为空并归入数据不足；空值不得替换为零。成交比例等于回撤段平均成交额除以上涨段平均成交额，分母必须大于零。

逐股输出保留 V2 原分类、V2.1 分类、锚点是否变化、成交比例是否变化和分类是否变化。比较结果只用于影子研究，不构成交易建议、概率、回测结论或生产规则升级依据。
