# V2 Diagnostic Factor Contract V1

Version `v2-diagnostic-factor-v1.1-anchor-corrected`. All observations are available at cutoff; gaps are omitted, never zero-filled. UP_DAY_RATIO20 uses up to 20 valid one-day returns and requires 15. RETURN_CONCENTRATION_20 is exposed unchanged from V1. Limit-up count is `NOT_AVAILABLE` because reliable board/security rule history is not locally contracted.

The recent peak is the most recent maximum adjusted close among the last 20 valid observations. Pullback amount fields use that identical latest peak. The advance segment includes the peak; the pullback segment begins after the peak, so the peak amount is counted once. Advance requires at least two observations and pullback at least one; otherwise all three amount diagnostics are NULL. Range diagnostics compare two non-overlapping ten-observation windows, each `(max(high)-min(low))/window-start close`. Volatility uses non-overlapping ten log-return windows with `ddof=1`. No narrow-range persistence value is implemented until a stable non-tuned definition exists.

Leader quality directions: higher TREND_R2_20, MDD20 nearer zero, higher POS60, and lower RETURN_CONCENTRATION_20 receive higher within-sector average percentiles. Every current member remains in the coverage denominator; only finite values enter the rank. Every percentile carries its finite-member count, coverage ratio, and rank denominator. A quality class requires at least five finite members and 70% coverage in the selected sector. These are separate descriptive dimensions, not statistically independent claims. STYLE classification uses only audited local names and conservative rules; anything not evidenced remains UNKNOWN.
