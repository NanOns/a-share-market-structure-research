# 第二版五类结构队列排序合同 V1

版本：`v2-queue-ranking-contract-v1.1-quality-dimension-name`

本合同只规定研究工作台中五类结构各自的队内次序，不改变已封存的第二版结构判定，不产生跨结构总分、交易评级或概率。一个股票可以同时进入多个队列；进入多个队列不会增加任何队列的排名。

共同规则：核心观察排在一般观察之前；其后按下表从左到右逐项比较；空值永远排在有效值之后；经济因子完全相同时共享经济名次，股票代码只用于稳定显示顺序。页面同时公布全队列名次和同研究带名次。

| 队列 | 依次比较的证据 |
|---|---|
| 稳健趋势 | 20日上涨日比例高、20日趋势稳定度高、60日趋势稳定度高、20日回撤较小、20日相对强弱高 |
| 强势回撤 | 成交确认成立、回撤成交比例低、60日趋势稳定度高、60日相对强弱高、20日回撤较小 |
| 突破准备 | 区间收缩比例低、实际波动收缩比例低、距20日高点较近、20日趋势稳定度高、20日相对强弱高 |
| 板块领先 | 强质量维度多、板块内20日相对强度高、板块内趋势稳定度高、板块内回撤质量高、主板块20日相对强度高 |
| 早期启动 | 5日相对强度高、5日涨幅高、成交活跃度高、20日趋势稳定度高、60日位置较低 |

这些名次只表示同日、同结构定义下的研究查看顺序。不同队列的第 1 名不能直接相互比较。
