## 1. 总体判断

通达信、腾讯/搜狐/证券时报、BaoStock、AKShare 和 AKQuant 可以形成很有价值的组合，但它们不是同一层的替代品：

| 组件 | 本质角色 | 建议定位 |
|---|---|---|
| 通达信本地数据 | 本地稳定行情库 | 行情主身份、离线主链、历史价格基座 |
| 腾讯/搜狐/证券时报 | 轻量在线行情入口 | 当日事实、换手率主备路由、临时补充 |
| BaoStock | 有明确 Python API 的数据服务 | 盘后历史行情、换手率、基础资料、财务和宏观主在线来源 |
| AKShare | 1000 余个公开数据接口的聚合采集库 | 官方/公开网站数据的广度扩展与交叉验证 |
| AKQuant | Rust + Python 量化研究与回测框架 | 因子实验、Walk-forward、回测、绩效与风险报告 |

正确方向不是把五套数据直接混成一张表，而是建立“来源独立、口径显式、按能力准入、物化后消费”的多源研究平台。

## 2. AKShare 的价值与边界

根据 [AKShare 官方文档](https://akshare.akfamily.xyz/index.html)，当前文档版本展示为 1.18.94，提供 1000 余个接口，覆盖股票、基金、指数、债券、期货、期权、外汇、利率、宏观、另类数据等类别。其离线接口注册表还提供 `ak.search()`、`ak.interface_info()` 和 `ak.list_categories()`，适合先检索能力，再为具体接口建立合同。

AKShare 的核心价值不是代替 BaoStock，而是扩大数据维度，例如：

- 上交所、深交所等官方市场统计；
- 个股财务、股东、分红、融资融券、龙虎榜、大宗交易；
- 行业、概念、指数及成分；
- ETF、基金、可转债；
- 宏观、利率、期货和商品数据；
- 市场情绪、资金、事件和部分另类数据。

但 AKShare 是采集适配器集合，不是单一权威数据服务。每个接口背后的真实来源、许可、字段、更新时间和稳定性都不同。官方说明也明确：数据来自公开来源、主要用于学术研究、不可用于商业用途；网页结构变化可能导致接口失效或被移除。因此不能把“安装了 AKShare”视为“1000 个接口全部获准上线”。

项目必须按“AKShare 接口 + 真实上游网站 + dataset”逐项建立合同。例如：

```text
AKSHARE / stock_sse_summary / SSE_MARKET_SUMMARY
AKSHARE / stock_szse_summary / SZSE_MARKET_SUMMARY
AKSHARE / 某东方财富接口 / 对应独立 dataset
```

同一个 AKShare 包中的两个接口也必须被视为两个独立 capability，不能相互继承授权与质量结论。

## 3. AKQuant 的价值与边界

根据 [AKQuant 官方仓库](https://github.com/akfamily/akquant)，AKQuant 是 Rust 核心加 Python 接口的量化研究和回测框架，提供：

- 高性能事件驱动回测；
- Walk-forward Validation；
- PyTorch / Scikit-learn 集成；
- TA-Lib 双后端及大量技术指标；
- Polars 因子表达式引擎；
- 网格参数搜索；
- 订单、风控、多资产组合能力；
- 收益、回撤、风险和基准比较报告。

它适合成为 V3.3 之外的**独立研究验证引擎**，不适合直接替换现有候选生成链路。首期最有价值的用途是：

1. 将 V3.3 每日候选和 170 日历史事实导出成稳定研究数据集；
2. 在 AKQuant 中复现简单、可解释的持有期规则；
3. 对 V3.3 的候选、Tier 和换手增强做独立 Walk-forward 审计；
4. 输出收益分布、最大回撤、暴露、换手和容量等诊断；
5. 与现有 Full LOO 形成互补，而不是以单次回测收益替代已有审计。

项目仍禁止自动交易。AKQuant 中的订单接口只允许用于离线模拟，不连接券商、不发真实订单、不形成收益承诺。

## 4. 建议的数据分层

```text
L0 原始来源层
  通达信 | 腾讯 | 搜狐 | 证券时报 | BaoStock | AKShare各上游
              ↓
L1 来源合同与采集层
  单源适配器、预算、许可、时间戳、错误码、原始字段身份
              ↓
L2 规范化事实层
  行情、换手、证券主数据、财务as-of、行业、事件、宏观
              ↓
L3 质量与共识层
  日期校验、行情指纹、单位转换、来源差异、capability gate
              ↓
L4 V3.3 产品层
  因子、候选、排序、证据、页面、每日真实前向数据
              ↓
L5 独立研究层
  Full LOO | AKQuant回测 | Walk-forward | 参数审计 | 风险报告
```

关键原则：L4 不能直接调用 L0；必须只消费已完成、已验收、带合同版本的 L2/L3 物化数据。

## 5. 数据域优先级

### 第一优先级：直接增强现有 V3.3

1. BaoStock 历史 `turn` 与换手率口径审计；
2. 交易日历、证券上市/退市/ST 状态；
3. 不复权日线 OHLCV、成交额交叉验证；
4. 股本、流通股本及股本变化事件；
5. 申万/交易所行业与指数成分的时点数据。

### 第二优先级：增加基本面解释能力

1. 财务报表和核心比率；
2. 业绩预告、业绩快报、正式财报；
3. 分红送转与股本变动；
4. 股东人数、机构持仓、限售解禁；
5. 融资融券、大宗交易、龙虎榜。

所有财务和事件数据必须保存 `pub_date`、`effective_date`、`received_at`，历史计算只能看到当时已经公开的信息。

### 第三优先级：市场环境与跨资产背景

1. 指数估值与宽基风格；
2. ETF 资金与行业基金表现；
3. 利率、货币、宏观数据；
4. 股指期货、商品期货及汇率；
5. 市场广度、涨跌停、融资余额等风险环境指标。

这些数据优先用于“市场环境标签”和解释，不应未经验证直接提高某只股票的分数。

### 暂缓

- 新闻/NLP 情绪；
- 社交热度与非结构化舆情；
- 高频分钟级全市场长期物化；
- 任何要求登录、验证码、动态签名绕过或许可不明的接口；
- AKQuant 实盘交易连接。

## 6. 多源冲突处理

同一字段出现多个来源时不做简单平均，也不使用“多数表决”覆盖事实。每条记录保留：

- `source_id` 与真实上游来源；
- `dataset_contract_id`；
- `source_as_of`、`received_at`；
- 单位与口径；
- 原始字段名及规范化字段名；
- 规范化哈希；
- 与本地主身份的指纹结果；
- `DISPLAY_ONLY`、`RESEARCH_ONLY` 或 `RANKING_ELIGIBLE` 状态。

来源优先级按数据域分别定义，不能建立全局“某来源永远优先”：

- 历史价格：通达信本地主身份优先；
- BaoStock：历史在线补充、换手与财务结构化主候选；
- 交易所官方数据：通过 AKShare 获取时，可成为对应市场统计的权威候选；
- 腾讯等：当日轻量事实；
- AKShare 聚合网站接口：扩展与交叉验证，逐接口准入。

## 7. 推荐实施顺序

### MS-01：数据能力目录

利用 AKShare 离线元数据检索，不发网络请求，筛选与 A 股项目相关的接口。为每个候选记录接口名、真实上游、数据域、参数、输出字段、更新频率、许可状态和预估价值。

### MS-02：首批 10 个接口小样本

只选高价值、来源清晰的接口，建议优先交易所统计、证券基础资料、财务公告、股本变化和指数成分。每个接口只取最小样本，验证字段、单位、日期和稳定性。

### MS-03：BaoStock B1—B3

按既有 BaoStock 方案完成严格串行连接、换手口径和 170 日小范围物化。

### MS-04：统一证券与日期身份

建立 `SECURITY_IDENTITY_V1` 和 `ASOF_TIME_CONTRACT_V1`，统一 `SH.600000`、`sh.600000`、`sh600000`、`600000` 等代码，同时保留原始代码。

### MS-05：基本面 as-of 层

先接 BaoStock 财务，再用 AKShare 中来源清晰的数据做交叉验证；禁止用报告期代替发布日期。

### MS-06：AKQuant 独立验证试点

选择一个最简单的 V3.3 候选持有规则，输入固定物化数据，以 AKQuant 复现并与现有 Full LOO 对账。只有成交日、价格、手续费、涨跌停、T+1 等假设全部显式后，结果才可进入审计报告。

## 8. 当前裁定

1. 认可 AKShare 作为广度扩展层，不能把它当成一个统一数据源；
2. 认可 AKQuant 作为独立研究与回测引擎，暂不接管 V3.3 生产计算；
3. BaoStock 仍是最适合先落地的结构化主在线来源；
4. 通达信本地主身份和离线主流程保持不变；
5. 腾讯、搜狐、证券时报继续承担当前轻量当日换手链路；
6. 下一步应先建立 AKShare 数据能力目录，不宜直接批量开发接口；
7. 所有新增模块继续遵守逐 dataset 合同、时间戳、能力门、原子物化和失败不阻断主流程的原则。

阶段结论为 `DEGRADED_PASS`：方向成立，官方能力和边界已确认；但任何 AKShare 接口或 AKQuant 回测在完成独立试点前，都不能被标记为生产可用。
