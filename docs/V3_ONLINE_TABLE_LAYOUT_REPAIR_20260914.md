## 证据与修复

用户截图显示题材成员弹窗中代码之后的列被自动表格布局压缩为竖排；七池说明列留白但只显示两行摘要，并需要额外按钮查看全文。根因是表格 `table-layout:auto`、非描述列没有宽度约束，说明列另有两行截断样式。

题材弹窗在宽屏放大至最高 1280px、窄屏不超出视口；两个表格改为固定布局、`colgroup` 明确前列宽度，末列占剩余宽度并保留换行。表格仍在最高 440px 区域内滚动，窄屏必要时横向滚动。七池去掉“读取”和“查看全文”按钮，切换池自动读取，说明全文直接在表格单元格内展示。
