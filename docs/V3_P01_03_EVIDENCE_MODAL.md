## 实施结果

### 证据入口和内容结构

- 个股透视证据页从 `<details>/<summary>` 折叠结构改为静态 `section.evidence-section` 分组，证据仍在同一个 modal 内呈现。
- 移除了“默认折叠”文案和表内展开语义；没有新增 href 跳转、嵌套抽屉或表内详情入口。
- 动态证据标题和数据继续使用 `textContent`、节点拼装和现有表格渲染，不把来源文本作为 HTML 执行。

### 弹窗合同和返回路径

- 增加 `p01-03.css` 并在旧页面之后加载：modal 使用 16px 外边距、`width: min(960px, 100%)`、`max-height: 85vh`；窄屏仍保持同一尺寸合同并使用内部滚动。
- 既有 `modal.js` 的 `role=dialog`、`aria-modal`、X、遮罩点击、Esc、点击内容不关闭和 `lastFocus.focus()` 保留并通过静态契约检查。
- 所有表格 action 继续生成 `type=button`，没有 href 导航。

### 请求竞态

- 技术历史、市场日明细、板块时间线、主线证据统一使用 `beginModalRequest()` 令牌和 `AbortController`。
- 新请求会取消同类旧请求；响应和异常处理均先校验当前令牌，旧对象的返回不能覆盖新对象。
- `api.js` 为上述下钻接口补充 options/signal 透传；没有改变接口数据合同或持久化边界。
