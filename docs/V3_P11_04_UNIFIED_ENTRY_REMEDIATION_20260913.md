# P11-04 V3 统一入口整改记录（2026-09-13）

## 阶段合同

本次整改依据 `docs/WORKBENCH_DUAL_TRACK_IMPLEMENTATION_SPEC_V3.md` §2、§10、§18.14、§20.3–20.8，以及 P11-04 入口交接要求执行。目标是把 V3 首页、旧能力归位页、在线事件能力和日常研究工具收口到一个 `/v3` 工作台入口；旧 API、旧表和兼容路由不在本次删除范围内。

## 整改前问题

- `/v3` 是独立的本地研究预览页，首页直接展示 P10-01 全量矩阵；
- 页面提供“旧功能 / 历史工作台”跳转 `/v2`，在线产品又分别暴露 `/v3/online`、`/v3/events`；
- 原有板块、个股、联动、市场和数据能力仍挂在另一套 V2 壳上，用户看到的是多入口而不是统一工作台。

## 已完成整改

1. `/v3` 改为统一工作台壳，复用已验证的页面内路由，主导航固定为：研究首页、板块研究、个股研究、联动筛选、市场与事件、数据 / 运维。
2. 研究首页按 V3 语义接入 `/api/v3/research/context` 和 `/api/v3/home/local`，只展示 CURRENT / POTENTIAL 双轨及 CURRENT_FOCUS / EARLY_FOCUS；没有资格项时保持明确空态，不以旧候选补位。
3. P10-01 历史矩阵不再占用 V3 首页；历史分析和兼容明细改为页面内按需展开，旧能力仍可从统一壳进入。
4. 市场与事件页在同一工作台内分区接入在线事件、题材、热门板块/话题、在线涨停事实，同时保留本地市场周期、平台热榜和本地梯队；在线和本地结果分源展示。
5. 主统一启动脚本以 `/v3` 为目标；`OPEN_RESEARCH_WORKBENCH.cmd` 继续打开 `/view` 作为 P11-04 要求的旧版只读回退。`/v2`、`/v3/online`、`/v3/events` 仅作为兼容路由保留，不作为 V3 主壳导航入口。
6. 针对首页缺少操作入口的问题，在 V3 首页补回“生成当前 V3 研究数据”“进入数据能力”“进入运维中心”三项明确入口。生成入口只在用户点击后提交 `BUILD_RESEARCH_V3` 任务，并以有界轮询反馈任务状态；首页加载不自动触发生成，运维危险操作仍由 `/operations` 页面承担。

- 浏览器真实验证：页面标题为“统一研究工作台 · V3”，首页双轨和市场与事件内嵌区可见，运行日志无 error/warn；
- 回归测试：`26 passed`；
- 当前真实发布日 `2026-09-10` 的双轨和清单为 0，是研究 run 的真实空态，不是页面故障或填充数据。
- 首页入口检查：存在 V3 研究生成按钮、数据能力入口和 `/operations` 运维入口；生成按钮带 CSRF 请求、任务编号反馈和 60 次状态轮询上限。
