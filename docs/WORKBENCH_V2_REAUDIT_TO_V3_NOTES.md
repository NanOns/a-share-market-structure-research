# V2再次内部审计：问题、修订与实施防漂移说明

日期：2026-09-11。主实施文档：[双线改造实施规格V3](WORKBENCH_DUAL_TRACK_IMPLEMENTATION_SPEC_V3.md)。原文：[Astra V2](WORKBENCH_DUAL_TRACK_ASTRA_AUDITED_PLAN_V2.md)，本轮保留不覆盖。

## 一、结论

用户指出的问题成立：V2偏重架构和风险纠偏，并未把“提前观察潜在板块→板块内提前观察股→后续是否转强”做成完整功能。照V2执行，仍可能只是优化当前强势榜，甚至出现板块有列表、成员仍按RET20排序的结果。因此V3是新的主实施规格，不是需要与V2拼接的补丁。

本次只新增Markdown文件。只读核对了app.py、两条关联路径、sector_cycle/sector_amount、技术/强度实际表模式、router/api/app前端、online源及能力配置、既有forward评估模块；未跑新算法或真实界面验收。

## 三、这次新增与明确后置的内容

新增：潜在三分支、两类成员直接预览、LOO共同支持主关联、双清单、潜在episode、信号后续结果表、三组基线、LIVE按板块报价和界面日期区分。

保留：联网、本地通达信基础、五类结构、MA/量额/RPS、新高、主线、矩阵、成员历史、属性集合筛选、在线事件及热榜。

移出首页但不删除：全结构候选、长期RET20代表榜、全板块长列表。不是把旧功能统统塞进审计入口，用户仍能在正常研究工具找到。

明确后置：V2股票“首次回撤”的完整长趋势episode，本版先采用有明确短窗的RECOVERY且不称首次；训练型AI模型、ATR/250日分位、灾备、清旧库、龙虎榜和事件日历。板块潜在episode是本版必做，与后置股票长趋势episode不同。

## 四、参数不是“已经验证的智能”

V3给出确定的首版门槛是为了防实现者任意发挥，不是声称这些数字已经能预测收益。CURRENT相对市场门、POTENTIAL三分支、SETUP收敛门均为PREVIEW工程初值。实现者先按规格交付，再拿固定样例和时间外结果决定是否修改，不自行把某个阈值改成宽松条件只为列表好看。

未来强势的价值应由“提前出现、后续可追踪、优于简单基线的证据”体现，不能仅由名字里出现AI体现。规则观察可先正常用，样本不足时状态为效果验证中；不需要封锁网络，也不要求外部审计签字。
