## 实现要求

1. 股票名称/代码/历史别名搜索；区分 `NOT_ELIGIBLE`、`UNKNOWN`、`NOT_IMPLEMENTED`、`NOT_IN_RESEARCH_UNIVERSE`、暂停上市等；研究池内未入选仍必须展示 Daily Profile。
2. 首屏：趋势、周/月背景、位置、均线、相对强弱、收敛、成交额、换手、突破/回踩/恢复、支撑状态、风险、市场环境、主行业与独立支持板块；列出数据日期、单位与窗口。
3. 生命周期：Maturity、Health、Validity、Tracking、Scenario、Risk、Quality 与可跟踪状态。Why Now 对比相邻交易日的 stage/domain/waiting/risk。
4. 研究决策区按 F（可观察事实）、R（价格结果）、H1/H2（竞争解释、反证、下一判别条件）、Waiting For、Invalid If 分开；若算法没有某 H，不让前端自行编造；中文解释避免“主力洗盘”无证据断言。
5. 正式可验证图表：至少60–120日大结构、20–40日近端日K及成交量，支持日/周/月K、MA/关键anchor/event、因子时间线和相对强弱图；复权方式/截止日清晰标记，不造分钟分时。
6. 板块上下文、Focus Timeline、从雷达/板块/首页深链个股、返回保持筛选；完整股票表分页排序导出（仅真实生产数据）。
7. 未入选说明分已满足/未满足/无法判定/未实现规则，列出导致结果的精确字段和限制，不做“值得/不值得”价值裁决。
