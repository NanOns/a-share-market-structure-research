# R4.3 独立外部验收与修复登记

本文件是工程交接登记，不是独立外部验收签名。R4.3 任务卡授权事后运营回算；该授权不等于对本轮生成字节的独立审计，也不等于生产切换批准。

## 独立验收范围

外审须取得本轮源码、Git LFS 实际对象和封存源的真实字节，核对 SHA、成员集合 S、多对多关系、日期有效证券、价格坐标、数值样本、原算法参数、未知原因及发布合同。只读取 LFS pointer 或工程自报 PASS 不满足门槛。

审查入口为同目录 `R4_3_EXTERNAL_AUDIT_HANDOFF.md`、`00_ENTRY_DRIVE_HEAD_AND_PROTECTED_DIGESTS.json` 和正式证据 01–13。验收记录必须绑定最终候选 digest、实际源码与数据 digest、审查范围、审查者、时间和问题处置，不得授权严格历史 PIT。
