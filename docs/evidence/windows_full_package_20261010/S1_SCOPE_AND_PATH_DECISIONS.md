# S1 依赖、来源范围与原件路径决策

实施不修改已接受算法原件或既有发布/恢复协议。真实生产两个Head及28765进程不接管。

## 原件与代码执行

程序包保留原目录布局及文件SHA清单。除了入口可达模块，还必须带齐发布policy引用的全部算法原件；其中两份原件只作合同身份使用，不应因AST未导入就漏包。

应用模块由PyInstaller的PYZ加载器加载。历史脚本把工作区/src加入sys.path时，运行钩子仍强制使用冻结加载器；未打包的本地模块拒绝加载，不能退回开发模块或解释器。原件路径用于身份、收据及既有算法要求的源码内省；原Rotation评估器自身的版本化源码变换按原合同执行，见下方冻结源码内省补充。

取得生命周期锁后，核验工作区与包的原件字节、原参数集和注册表。源码身份映射到工作区中相同SHA的原件，解决派生收据要求ref位于工作区内的问题。包资源、持久工作区和来源输入分别保留路径身份。应用代码与算法原件的SHA不因映射改变。

TDX备用下载走固定原R3模块调用，沿用原官方URL、有界请求、下载/ZIP/SHA核验；没有sys.executable递归启动或任意脚本分派。开发V4入口也使用同一生命周期和来源适配层，运行中原生产进程不会因此被重新加载或切换。

## PKG-X01 独立来源范围审计

隔离回放重捕获的原ZIP SHA为635c775940b2efdb8c9779c9898306c475822517f072c0eddcec8273b14e7ad6。原提取器得到5559条目标记录；原BaoStock已有5224条沪深证券记录，其中5210条交易、14条停牌。349条额外目标记录全部是北交所；沪深没有缺失，停牌证券没有意外当日记录。

原来源门要求交易代码集合精确一致，直接传全量TDX目标记录会被DAILY_COVERAGE_RECONCILIATION_REQUIRED拒绝。这是独立来源范围问题，不把它混成托盘缺陷或修改原算法来绕过。

新增TDX_SH_SZ_NATIVE_SOURCE_VIEW_V1，只排除准确匹配BJ.加六位数字的范围外记录；沪深、未知代码、停牌冲突和所有数值原样保留。视图绑定完整原目标artifact/SHA、原ZIP、349条排除清单及原来源可用时间。未知或缺失证券、价格差异仍交给原来源/身份门拒绝。14条停牌记录沿用原BaoStock事实，没有造当日Bar。

实际原门验证：5210条视图通过来源准入；注入沪深价格错误、缺失沪深Bar均被原门拒绝，旧Head不变。原ZIP与目标提取文件保留，完整数值/frozen验收结果单列，外审仍NOT_GRANTED。

## 实例与资源

生命周期锁、实例ID、真实进程映像路径、PID创建时刻、工作区和包版本共同标识应用；虚拟环境启动器路径另记。状态收据与实例ID不一致时显示初始化/无法确认，不显示旧实例的RUNNING。已有Windows托盘通过核验所属PID的固定只读消息显示状态，不自动重启停止的引擎。

Windows监听保留独占端口；关闭HTTPServer默认复用选项，避免与SO_EXCLUSIVEADDRUSE冲突。端口绑定在恢复和任务初始化之前成功占有并保持，不使用试探后释放的空隙。退出显式隐藏图标、关闭消息循环和引擎；会话通知与真实安全退出分别记，模拟不代替Windows重启。
## 冻结源码内省补充

实际完整数值回放在原Rotation重构评估器处发现Python 3.13 `inspect.getsource()`读取PYZ相对`code.co_filename`失败。此失败发生在CAS前，隔离前驱Head和真实生产Head均未改变。原算法通过源码内省及既有版本化变换构建评估器，这是已接受算法本身的执行路径，不能删掉、改数值函数或伪造源码SHA。

冻结路径适配因此向`linecache`登记包manifest逐字节SHA核验过的源码原件，同时保留PYZ加载器。只提供清单中的原件，不从开发PATH加载模块；已接受Rotation评估器自身的原有`exec(compile(...))`保持原样，应明确记录为合同内源码变换，而不是笼统写“没有任何源码执行”。可达BaoStock SDK源码内省同样保留包内原件和明确身份。轻量EXE预检先直接调用原评估器并验证SDK来源函数可内省，再进行完整数值重跑；前一个失败EXE不授予S1通过。

## 工作区合同与用户入口补充

完整数值回放还发现提前导入的模块已把`ROOT`绑定到资源目录。取得工作区锁并确认模块原件SHA相同后，路径适配同时映射这些模块中指向资源目录的绝对Path常量；业务函数、参数和注册表不改变。完整重算前先执行原D0/D2及预观察合同校验，缺失合同直接失败。失败候选及其真实退出证据保留，不授予通过。

打包首页通过展示层脚本说明捕获条件，并显示自动日更暂停状态；原HTML原件身份保留。状态读取使用既有SQLite只读连接，不为显示状态恢复队列。实际冻结EXE分别核验首页脚本与暂停状态。

生命周期锁之外，首次启动还只读识别同一工作区已运行的两个已知旧Python入口；发现后在创建锁和初始化数据库之前拒绝。开发入口及实际旧启动脚本的新启动路径均接入同一生命周期。正在运行的旧生产进程不被重载、关闭或接管。
