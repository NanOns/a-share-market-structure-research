# 整体打包 S2 实施合同

合同：`V4_WINDOWS_PACKAGE_S2_EXECUTION_V1`，继承canonical R2.1设计、S0依赖与安全边界及S1精确EXE证据。S1的冻结EXE完整链路通过前，仅准备安装器源码与编译语法检查；不执行安装、升级或卸载验收。安装构建器强制读取通过的S1报告并绑定同一EXE SHA。

范围：一个用户可见Windows x64安装EXE，内含完整onedir程序；安装、同版修复、独立版本部署、兼容回退机制、默认保留数据的卸载和可选当前用户登录自启。外层.NET Framework 4.x入口在启动Inno核心前设置G盘TMP/TEMP/TMPDIR并验证核心SHA，解决安装核心首次解压早于脚本运行的问题。Windows 10/11内置.NET 4.x是明确系统前提；用户无需Python/pip/开发工具。构建工具由官方发布物及签名核验，构建器与工具身份另行记录。

安装目录限G盘程序版本根，不能与持久工作区互相包含，拒绝重解析目录。安装、修复、卸载期间排他打开既有工作区锁；应用未安全退出时拒绝，保持默认不自动关闭进程、不重启Windows、不启动生产应用。首次迁移未建立生命周期锁时，安装入口要求既有28765服务先退出；已核验工作区和只读TDX根后才建立锁文件。不会自行停旧Python服务。包校验失败不授予接管许可。

安装只写程序目录、快捷方式和选中的当前用户登录注册表值。工作区的研究Head、原件、日更数据库、取消记录、暂停设置和日志不覆盖、不迁移。用户首次自启默认未选；修复/新版沿用已开启的自启选择。卸载只在该注册表值确实指向当前被卸载EXE时清除，避免旧版卸载删除新版入口。回退只切程序和入口，不恢复旧Head；本轮同一EXE两个目录的回退演练不冒充跨历史代码/schema兼容证明。

QA使用独立G盘工作区和`DaAV4PackagedIsolatedQA`注册表值、独立AppId、无生产快捷方式，验证真实安装器部署/修复/版本切换/锁拒绝/卸载及原Head、SQLite和用户取消/暂停记录逐字节保留。包内资源校验由实际安装后的EXE执行。单独记录缺盘、非法路径、无网、端口冲突、实际崩溃与恢复覆盖；已有S1证据可精确引用。

完整程序文件清单覆盖EXE、DLL、PYZ、静态资源及清单本身的身份。Inno部署后先逐文件SHA核验，再由实际安装EXE核验资源；外层入口复核完整清单后才报告成功。每个程序版本目录派生独立卸载AppId；旧版卸载仅删除仍指向本版本的快捷方式和登录值，保留新版入口。初次迁移另对同工作区旧启动收据的PID、映像和创建时间进行只读核验，拒绝已知旧服务仍运行的情况。

只读来源检查覆盖配置中的每个TDX根，而非仅固定D盘路径。程序目录、锁文件及G盘安装临时目录与配置来源重叠时拒绝；尤其不能把临时根的子目录配置为来源后仍向该子目录解压。隔离QA临时声明既有G盘安装缓存为只读来源，要求安装入口拒绝且所有来源文件大小、修改时间和文件集合保持一致，然后恢复隔离合同原字节。真实来源合同不修改。

实际Windows重启/登录、物理鼠标托盘动作与两个物理显示环境、生产接管均保留独立结果，不以程序驱动托盘测试、窗口尺寸模拟或HKCU写入证明代替。当前实现请求不隐含关闭正在提供服务的生产PID或立即重启用户电脑。先交付可审阅安装包、验证报告和可撤销接管步骤，只有独立授权后才执行真实生产切换/重启验证。提交推送不代表外部接受，也不自动授予下一门权限。
