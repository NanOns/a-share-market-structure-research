# 大A交易整体安装版使用说明

这份实现采用用户主动要求、适合当前阶段的完整目录打包：一个安装EXE部署整个运行程序，包含Python运行时、数值依赖、网页、托盘和SHA核验资源。用户无需安装Python或pip。当前目标为Windows 10/11 x64、已有且经过核验的G盘研究工作区；不创建空行情库，也不迁移TDX源目录。系统内置.NET Framework 4.x用于安装入口。

## 使用入口

工程交付目录：`G:/codex work/大A交易_交付/windows_package_v1`。实际交付版本、EXE SHA、安装器SHA和通过项以本目录的交付收据、仓库S1/S2收据为准，旧测试候选不是用户安装入口。

安装器部署到`G:/codex work/大A交易_安装版/releases/<包版本>`，默认工作区仍为`G:/codex work/大A交易`。程序资源和数据分开，运行日志位于工作区`runtime/desktop`。G盘不可用时明确失败，没有C盘缓存回退。

当前旧Python生产服务仍在28765运行。安装版的实际接管属于独立范围：先核对旧进程、当前任务、安全边界和两个Head，再安全退出旧实例、确认端口和锁释放、安装并启动新实例。首次安装若尚无生命周期锁且28765仍被旧服务使用，会拒绝安装，不自动结束旧进程。请不要同时手动启动源码和安装版。工程包通过不等于已接管生产。

完成接管后，双击桌面“大A交易”，托盘出现并启动内部引擎；现有网页仍是`http://127.0.0.1:28765/v4`。重复启动使用已有工作区实例；引擎停止时托盘仍保留，需从已有托盘手动启动。

## 托盘操作

- 打开研究页面、查看运行状态、打开日志目录。
- 启动引擎、安全停止引擎、安全重启引擎。重启只重建当前版本内部HTTP服务和任务线程。
- 暂停或恢复自动日更，设置落在既有任务数据库；用户取消的任务不会因重启自动恢复。
- 维护请求等待任务安全边界；HTTP读服务保留到发布回读完成。120秒提示仍在等待，不自动杀进程。在最终关闭开始前可取消本次维护请求。
- 退出大A应用先安全停止引擎，再移除托盘并释放工作区锁。
- 登录Windows后自动启动可选，首次安装默认不勾选；已开启时修复/新版沿用。真实采集要求电脑可用、用户已登录、应用及引擎运行、日更未暂停且来源可用。休眠、关机、未登录或停止引擎期间不保证采集；补日更不能补造历史首次观测。

运行状态分别显示包资源身份、工作区、引擎健康和数据新鲜度线索。托盘存在或旧数据可读本身不能证明当前采集正常。正式准入、历史PIT和生产权限仍沿用既有合同。

## 升级、修复与卸载

先从托盘安全退出；锁未释放时安装、修复和卸载会拒绝。新版放到独立程序版本目录，经资源校验后切换入口，不覆盖工作区Head、原件、SQLite、用户取消记录、暂停设置或日志。回退先验证代码/schema兼容，只切程序和入口，不恢复旧Head。

卸载仅移除该程序版本及它自身的入口；默认保留研究工作区。旧版本卸载不会删除指向其他版本的登录自启。安装日志及安装核心临时文件留在`G:/codex_tmp/package_setup`供诊断，属于工程缓存，不是行情数据。当前安装包未做发行代码签名，SHA用于绑定交付物身份；外部接受和实机验收状态见收据。

## 验收解释

冻结EXE完整数值回放明确标为REPLAY，保存来源原观测时间、输入SHA、实际执行时间及事务。它证明打包后原日更/发布/恢复可执行，不冒充真实当日首次采集。真实Win32托盘的程序驱动检查与物理鼠标、两个物理显示环境、实际Windows重启登录分别记录。实际生产接管只有独立授权与证据齐备后才执行。
