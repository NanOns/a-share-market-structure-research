# R4.2.1 source and taxonomy migration

The user-authorized R4.2.1 task is stored under docs/evidence/r4_2_1_20261009.
TDX_PACKAGE_DELTA_V1, historical seals, original four-day candidates and accepted
heads remain immutable. Typed V2 verifies complete parent/current ZIP SHA, CRC,
paths and duplicates. A-stock consumer rows require exact hash-bound canonical
identity, lifecycle dates and dated provider roster evidence; code ranges grant
only inference/exclusion, never positive stock authority. Foreign and unknown
entries retain byte hashes, validation and revision diagnostics. Invalid,
removed, truncated or rewritten canonical stock entries block the target scope.

execute_r4_2_typed_delta.py produces real four-session rows and independent
struct-decoded comparisons. The DM01 --typed-scope-v2 option consumes these
producer/policy/hash-bound artifacts, then executes bounded BaoStock date-level
smoke and the existing capture_baostock_daily_update implementation. A new read
capability capsule is corrected-only; the original same-natural-day PIT manifest
is never replaced. GBBQ/lifecycle/special-phase probes retain concrete blockers.
V2 is forbidden from entering the old V1 AS_RECORDED source freeze and promotion.
Successor registry and source freeze admission are separate staging objects.

TDX_INDUSTRY_CONCEPT is the sole primary sector taxonomy. The versioned consumer
adapter rejects BAO_CSRC namespace, auxiliary fields and cross-taxonomy priors.
CSRC outputs are recursively csrc_ prefixed under a separate auxiliary tree.
Absent accepted exact-date TDX memberships produce field-local UNKNOWN; stock
RAW/Core/Profile and member-independent Seed/PREWATCH remain usable candidates.
Accepted 9/30 TDX 378/50162 identity/digests remain unchanged.

Production release requires an independently accepted corrected scoped successor
contract. Current all-nine PIT publication authority cannot grant that permission.
The isolated E-drive successor CAS/NOOP/stale/bad-permission/failure/rollback checks
demonstrate candidate mechanics only. No 10/08 production cutover is claimed.
