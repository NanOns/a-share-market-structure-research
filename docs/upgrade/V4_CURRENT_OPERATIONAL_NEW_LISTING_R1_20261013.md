# 当日日更新股增量 R1

用户直接授权修复今日新上市证券入库并验证日更。当前范围为带日期桌面运营研究，不授予严格历史首次可用/PIT、全产品或交易用途。

原接受身份文件、政策、算法和旧 Head 字节保留。新增版本适配器在原完整三源价格/日期/唯一性校验后，识别新增而非消失代码。仅允许 BaoStock 单证券 basic 的类型1、状态1、上市日等于目标交易日、无退市日期，结合同日两源独立原生 bar 对照和已冻结完整证券池。每次最多20只、每只单次最多2行/1页，以现有受限请求预算和SDK时钟保存原始事实。重复、错码、未来上市、历史未知或消失证券不推断，保持阻断。

新增证券采用已有稳定ID公式，追加不可变身份版本。新版本传入 source readiness、Owner generation、当天 lifecycle、Core/Profile/板块/市场/Focus/周期/PG。旧 Data Head 只在私有IO scope中映射到包含新身份的版本，并不修改真实旧 Head；上市日期前不得出现交易历史，历史不足因子保持 UNKNOWN。成员关系仍只依据原成员源，不凭新股名称合成。

验收必须包含日期前排除、错码/重复/冲突/非股票/退市/未来日期拒绝、真实当日新股 metadata、原源保护、来源身份和Owner数值守恒、PG与原子发布后七路HTTP同版。实际生成和发布未通过前不写日更成功。
